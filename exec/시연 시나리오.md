# STEP 3. 롱폼 영상 전체 분석 시작

## 영상

- 알파아이 (롱폼 / 위험)

## 시연 내용

- ‘전체 수사’ 선택
- ‘팩트체크 수사 시작’ 버튼 클릭
- 분석 로딩 화면 확인

## 발표 멘트

> “현재 영상의 자막과 메타데이터를 수집한 뒤, AI가 핵심 주장을 추출하고 외부 웹 정보와 비교 검증을 수행하고 있습니다.”
> 

> “롱폼 영상은 자막 길이가 길기 때문에 분석에 다소 시간이 소요됩니다.”
>
